# FORGE — Built to Outperform

Premium gym e-commerce storefront for **FORGE Athletics**: performance apparel, accessories, supplements, and training equipment.

Dark cinematic identity, scroll-driven motion, and a full client-side shopping flow (cart, wishlist, search, filters, checkout).

## Run

```bash
cd forge
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

```bash
npm run build    # production build
npm run preview  # serve the build
```

## What’s included

- Homepage: cinematic hero, categories, trending grid, pinned shop-by-goal, stats, limited drop + countdown, community, newsletter
- Shop with category routes, filters, and sort
- Product detail: gallery zoom, size/color/qty, reviews, FAQs, recommended
- Slide-out cart with free-shipping progress and discount codes `FORGE10` / `VOLT15`
- Search overlay, wishlist, account, checkout (demo — no real payments)
- Cart and wishlist persist in `localStorage`

## Stack

React 19 · TypeScript · Vite · React Router · Framer Motion · Lenis · original generated photography
