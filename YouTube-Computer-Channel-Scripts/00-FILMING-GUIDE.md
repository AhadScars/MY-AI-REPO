## PEHLE YE PADHO — copyright (strike se bachna)

**Mat uthana:** Hardware Unboxed, Linus, Paul’s Hardware, Trakin, Technical Guruji, koi bhi YouTuber ki clip, unka benchmark graph video se crop karke.

YouTube Content ID + copyright claim = video mute / strike / monetize band.

**Use kar sakte ho (NET B-ROLL):**

| Source | Kya lo | Kaise |
|---|---|---|
| **Pexels / Pixabay / Mixkit / Coverr** | RGB PC, typing, city, cables, fans | Download, no credit required (credit do to pro) |
| **NVIDIA / AMD / Intel / Microsoft official YouTube** | Product spin, keynote 3–8 sec | Voiceover + commentary = fair use. Unka poora scene mat churao |
| **Official press renders** | GPU/CPU product shots | Brand site / newsroom |
| **Tumhara screen record** | Amazon.in, MDComputers, PrimeABGB, YouTube search, Task Manager, game | Best footage — 100% tumhari |
| **Game official trailers** | 4–6 sec, upar tumhari awaaz | Title card: game name. Poori cinematic mat daalna |
| **Wikipedia / Wikimedia** | Chip photos, old diagrams | Check license |
| **Tumhara phone** | Face, haath, desk, Amazon box, local shop | Har video mein yeh sabse important |

Har net clip ke neeche chhota text: `Clip: NVIDIA official` / `Stock: Pexels` / `Price: Amazon.in screen record`.

**Numbers ka rule:** kisi lab ka graph copy-paste mat. Number bolo “public reviews ke according ~X FPS”, screen pe **apna typed card**. Source naam le lo: “Hardware Unboxed / Digital Foundry ke tests ke hisaab se”.

## FACE-CAM setup (har video)

Phone landscape, **eye-level**, window **45° left**. Mic PC pe, awaaz OBS se.

Kapde: ek solid t-shirt (black / navy). Har video same — channel yaad rahega.

Background: saaf deewar + ek monitor glow. Kapde / bartan bahar.

### Camera language (scripts mein yehi labels)

| Label | Matlab | Movement |
|---|---|---|
| **FACE FULL** | Face 70–80% frame | Slow **push-in** hook pe, static baaki |
| **FACE REACT** | Number ke baad cut | 1.5–2.5 sec, eyebrows / “are yaar” |
| **PIP** | Face chhota bottom-right | Screen ke upar, jab demo ho |
| **OVER-SHOULDER** | Phone thoda peeche-side | Monitor + tumhara kandha |
| **HANDHELD DESK** | Phone haath mein | Amazon page / keyboard follow |
| **NET B-ROLL** | Stock / official 3–6s | Slow zoom 105%, kabhi bhi 12s se lamba nahi |
| **PRICE-CAM** | Screen record shop | Cursor highlighter ON |
| **GFX CARD** | CapCut text | Big number, red/green |

Har 20–25 second mein **face dikhe**. Algorithm + trust dono ke liye.

## Thumbnail formula (har script mein prompt hai)

- **16:9**, face **left** (shocked / angry / thinking)
- Product **right** (GPU / RAM / PC)
- 2–4 huge words, Hindi + English mix
- Red circle / green tick / “2026” stamp
- Face photo ** CapCut mein khud chipkao** — AI face mat, YouTube thumbnail pe fake face se trust toot’ta hai

Prompt ko Imagine / Phot.AI / Bing Image Creator mein daalo, phir **apna real face** overlay.
