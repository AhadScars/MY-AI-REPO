# DigiHub Solutions Website

Full software company site — not only billing.

## Services
- **Android apps** (APK / Play Store)
- **iOS apps** (iPhone & iPad)
- **Web applications** (portals, SaaS, dashboards)
- **Websites** (business, landing, e‑commerce)
- **Custom software** (desktop, APIs, automation)

## Ready-made products
- Pharmacy POS · Restaurant POS · Hotel PMS · **School Management**

## Pages
- `index.html` — full software positioning + services + products
- `services.html` — all custom service lines
- `products.html` — ready-made catalog
- Pricing, features, about, contact, brochure, careers, license, how-it-works

## New features
- Services page + nav dropdown
- Contact form: Android, iOS, web, website, custom + POS options
- Pricing: what’s included + how you get started (POS)
- FAQ accordion (Home + Pricing)
- Extended About + team + timeline + mission
- Customer count mock (animated stats)
- Brochure page (print / Save as PDF)
- Careers page
- Multi-currency display (INR, USD, EUR, GBP, AED)
- Sticky free-trial bar (all pages)

## Configure
Edit `js/config.js` for WhatsApp, email, support hours, prices, FX rates, stats.
